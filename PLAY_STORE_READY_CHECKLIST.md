### Step 2: Create App in Play Console
1. Go to: https://play.google.com/console
2. Click "Create app"
3. Fill in basic details:
   - App name: Eco Sudar
   - Default language: English
   - App or game: App
   - Free or paid: Free
4. Accept declarations
5. Click "Create app"

### Step 3: Complete Store Listing
Navigate to "Store presence" > "Main store listing":

1. Upload icon (512x512) ✓
2. Upload feature graphic (1024x500)
3. Upload screenshots (minimum 2)
4. Add short description (80 chars)
5. Add full description (4000 chars)
6. Select app category
7. Add contact email
8. Add website (optional)

### Step 4: Set Up App Content
1. **Privacy Policy**: Add your URL
2. **Content Rating**: Complete questionnaire
3. **Target Audience**: Specify age groups
4. **Data Safety**: Declare data practices

### Step 5: Upload AAB
1. Go to "Release" > "Production"
2. Click "Create new release"
3. Upload your AAB file
4. Add release notes:
   ```
   Initial release of Eco Sudar
   - [List your key features]
   ```
5. Save (don't submit yet)

### Step 6: Review Everything
Check all sections are complete:
- [ ] Store listing
- [ ] Content rating
- [ ] Target audience
- [ ] Data safety
- [ ] Privacy policy
- [ ] AAB uploaded

### Step 7: Submit for Review
1. Review your app listing preview
2. Click "Send for review"
3. Wait for Google's review (1-3 days)
